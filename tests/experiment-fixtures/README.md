These fixtures were captured by the original Go `XsimWorldInputs` and its owning sensor/config functions before their removal. `source-receipt.json` identifies the baseline Git HEAD and the **actual capture worktree** file hashes, including the concurrently updated public asset projector. The scientific compiler outputs were not computed by the new native parser. Raw authored sensors and generic opening/deployment/declaration facts were mechanically attached to the public input; `UseNumber` retained exact int64 nanoseconds.

`index.json` is the exact captured index (SHA256 recorded in the receipt); `manifest.json` wraps that unchanged ordered array under `cases` because the native bounded reader accepts objects. Each original input/expected file's byte hash is in `caseFiles`. The 61 cases comprise 25 exact configurations, 35 original refusals and one `expectedNoWorld` result. That last case belongs to the workflow's no-world branch; a direct bootstrap with world-start disabled is refused rather than fabricating a native world. `experiment_test.cpp` adds strict bootstrap and explicit empty raw sensor controls without changing the captured expected results.
